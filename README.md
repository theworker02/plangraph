# plangraph

Plan CSV/TSV graph tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/plangraph/

## Install / run

```bash
git clone https://github.com/theworker02/plangraph.git
cd plangraph
node src/cli.js
node --test
```
